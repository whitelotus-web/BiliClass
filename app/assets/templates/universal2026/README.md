# BiliClass Universal 2026

Teacher-supplied design pack integrated on 2026-10-16 from
`BiliClass_Universal_2026_Tron_Bo.zip`. The three editable PowerPoint files and
manifest are bundled application resources, not a teacher's lesson library.
The supplied manifest states that these are original designs authored for
BiliClass, without redistributed third-party PPTX elements.

The ZIP's JavaScript generator and embedded task prompts are not executed or
distributed. The PPTX assets are preserved as supplied. The application reads
the manifest's layout numbers and adapts copies of their native shapes.
Generated text uses Arial for compatibility with Office 2019; some Aptos italic
glyphs in the supplied templates rendered incorrectly on the test machine.

Preset compatibility: `standard` → `CLASSROOM`, `visual` → `VISUAL`,
`practice` → `PRACTICE`. Each file is a library of 23 layouts, not a finished
23-page lesson. See `docs/UNIVERSAL_TEMPLATES_RC47.md` for operational scope.
